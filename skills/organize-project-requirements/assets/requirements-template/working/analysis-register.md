Use one primary classification per atomic item: problem/evidence, outcome/measure, stakeholder need, term/fact, scenario, business rule, constraint, assumption, dependency, risk, decision, open question, stakeholder/solution/transition requirement candidate, or design candidate. Derived BRS content receives its own lifecycle status; do not copy that status onto its source evidence.

Use `Draft`, `Complete`, or `Superseded` for Analysis Items. `Complete` means the analysis has an explicit destination or terminal rationale; it does not approve derived requirements.
