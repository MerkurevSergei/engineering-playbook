# Capabilities

Each child directory owns one coherent business ability:

```text
CAP-001-<business-ability>/
  README.md
```

Start with one page containing the capability outcome, boundary, owner, participants, information, events, rules, scenarios, constraints, decisions, evidence, and downstream links. Split `rules.md`, `scenarios.md`, or `models/` only for concrete ownership, reuse, approval, tooling, assurance, access, or review-size needs.
